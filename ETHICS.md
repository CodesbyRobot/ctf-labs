# Ethical Use

This repository exists for defensive education and authorized practice.

## Allowed use

- Running the included challenges on your own machine.
- Teaching in a lab, classroom, or competition where the organizer controls the targets.
- Adapting the synthetic examples for secure-code reviews and awareness training.

## Not allowed by this project

- Pointing challenge techniques at systems without explicit permission.
- Using real credentials, private data, malware, persistence, or destructive payloads.
- Publishing challenge contributions that contain live secrets or identify real victims.

## Design standard

New challenges should be self-contained, reproducible, resettable, and safe by default. Network services must bind to loopback unless an organizer deliberately changes the configuration inside an isolated lab.
