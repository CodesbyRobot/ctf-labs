# Contributing

Contributions are welcome when they keep the repository safe, clear, and beginner-friendly.

## Challenge requirements

1. Use only synthetic data and documentation IP ranges.
2. Bind network services to `127.0.0.1` by default.
3. Avoid malware, credential theft, persistence, destructive behavior, and real-world targets.
4. Include a challenge README, a solution walkthrough, and an automated integrity test.
5. Explain the defensive lesson and how the underlying weakness should be fixed.

## Local checks

```bash
make test
```

Submit focused changes with a clear description of the challenge, intended learning outcome, and safety controls.
