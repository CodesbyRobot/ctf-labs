# Challenge 1: Encoding Trail

A teammate recovered the text in [`artifact.txt`](artifact.txt). It looks unreadable, but no secret key was used.

## Goal

Recover the flag in the form `flag{...}`.

## Clues

- The artifact passed through three reversible transformations.
- Work from the outside layer toward the original message.
- Common command-line tools and a short Python script are enough.

## Lesson

Encoding changes representation. It does not provide confidentiality by itself.
